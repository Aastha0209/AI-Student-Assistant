# 🎓 AI Student Assistant

A modern student productivity platform built using **HTML, CSS, JavaScript, Firebase Authentication, Firebase Realtime Database, and Firebase Hosting**.

The application helps students manage attendance, tasks, notes, timetables, announcements, and study assistance from a built-in AI chatbot.
